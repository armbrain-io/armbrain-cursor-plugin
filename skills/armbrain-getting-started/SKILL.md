# Armbrain getting started

1. Confirm the Armbrain connector is installed and authorize with OAuth when prompted (Armbrain account at https://armbrain.io). Do not ask them to paste API keys into chat.
2. Call `system` with action `whoami` to verify identity and list recent minds.
3. If they name a client, switch to that mind before any client work (`switch_client` / mind tools). Never blend clients.
4. Offer one concrete first win: morning `briefing`, `prep_meeting` for their next call, or guided onboarding for a new client mind.
5. Remind them: lasting client facts go into Armbrain, not chat-only memory. Draft external sends; wait for explicit approval before sending.
