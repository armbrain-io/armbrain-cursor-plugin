# Armbrain client memory

## Rules

- Always identify and switch the correct client (or prospect) mind before recall or write.
- Prefer Armbrain search/store tools over inventing history from general knowledge.
- Sandbox clients: never copy one client's facts into another's mind.
- Show extracted facts for confirmation before bulk store when ingesting documents.
- External email/Slack/calendar mutations: draft first; send only with clear user approval.

## Common flows

- **Meeting prep:** switch mind → search recent decisions, open loops, stakeholders → build brief.
- **Quick capture:** store a note/fact with tags when the user says "remember" or "add to the agenda."
- **Brand voice:** pull brand voice from the active mind before drafting client-facing copy.
- **Business OS / L10:** use Armbrain business_os tools for rocks, scorecard, and issues — do not invent EOS data.
